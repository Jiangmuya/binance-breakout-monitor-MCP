# Excel筛选兼容修复（2026-10-27）

导出程序曾在同一区域同时输出表格级和工作表级AutoFilter，Excel打开时会移除冲突的表对象。修复仅删除工作表级重复筛选，保留表格级筛选、关联关系、数据、红字、框线及前六行冻结。
